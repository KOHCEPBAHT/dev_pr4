# П04. Деплой веб-сервера с помощью Ansible

Сделать ansible-плейбук, который установит на целевую машину nginx и скопирует туда индексный файл

0. Отключить скрипт weather.sh из прошлой работы (crontab -e)
1. Сделать вторую виртуалку
2. Склонировать первую вм с опцией «сгенерировать новые мак-адреса»
3. Создать в virtual box – инструменты – Сеть NAT
4. Обе вм переключить в новую Сеть NAT с адресацией 10.0.2.0/24
5. Задать статические IP адреса на обоих вм
6. Организовать проброс портов 22 на обе вм и 80 на вторую вм
7. Создать и скопировать с первой на вторую вм SSH ключ (в пользователя runner)
8. На второй вм создать юзера runner с правами sudo без пароля
9. На первой вм
10. Установить ансибл
11. Написать плейбук – install nginx
12. Создать файл inventory с адресом второй вм
13. Положить шаблон index.html
14. Выполнить плейбук
